# B0 — Repo modernisation + self-hosting harness + baseline audit

**Stage goal:** put the .NET guardrails in place (net10, analyzers, warnings-as-errors, central
packages, solution file) and stand up the harness that lets Conductor drive itself — without
changing any runtime behaviour. This stage is the foundation every later stage is held to.

**Sessions:** ~2. **Persona:** (none / default). **Depends on:** nothing.
**Branch:** `feat/baton-b0`.

## Why this stage exists (findings)
- F-10: `net9.0`, no `.editorconfig`, no `Directory.Build.props`, no analyzers, no solution file, no
  warnings-as-errors. The code is clean but unguarded against drift, and this plan demands SOLID +
  modern-C# discipline that must be *enforced*, not hoped for.
- D-1/D-12: Conductor must drive its own iteration under strict tooling.

## Requirements
- R0.1 Target `net10.0` for `src/Conductor` and `tests/Conductor.Tests`; solution builds and all 56
  existing tests pass with **zero behaviour change**.
- R0.2 `TreatWarningsAsErrors=true`, `EnforceCodeStyleInBuild=true`, `AnalysisLevel=latest`,
  nullable + implicit usings retained, centrally in `Directory.Build.props`.
- R0.3 `Meziantou.Analyzer` + built-in `Microsoft.CodeAnalysis.NetAnalyzers` enabled with a **curated**
  ruleset (not the raw firehose) — severities in `.editorconfig`, rationale in an ADR.
- R0.4 Central package management (`Directory.Packages.props`, `ManagePackageVersionsCentrally=true`).
- R0.5 `Conductor.slnx` (modern XML solution) as the single build entry (`dotnet build Conductor.slnx`).
  NOTE: `Conductor.slnx` already exists on `master` (verified) — adopt/verify it, don't recreate.
- R0.6 The self-hosting harness: `CONDUCTOR-START.md` (exists), `plans/conductor.self.plan.json`
  (exists) verified loadable by the stable driver; `fake-agent.ps1` scenarios extended so the loop
  is smoke-testable token-free.
- R0.7 A baseline audit doc capturing current coupling/debt (evidence for later stages).

## Tasks → checkpoints
- **B0.1** — net10 migration + `Directory.Build.props` + `Directory.Packages.props` (+ verify existing `Conductor.slnx`).
  - Bump both TFMs to `net10.0`. Move common props (Nullable, ImplicitUsings, LangVersion, analysis
    flags) into `Directory.Build.props` at repo root. Move package versions into
    `Directory.Packages.props`. `Conductor.slnx` already exists — verify it references both projects.
  - Gate: `dotnet build Conductor.slnx` 0 warn/0 err; `dotnet test Conductor.slnx` 56 pass.
- **B0.2** — `.editorconfig` + Meziantou.Analyzer + NetAnalyzers, curated ruleset, warnings-as-errors.
  - Add analyzers as PackageVersion + PrivateAssets. Author `.editorconfig` (style + rule severities;
    start from `docs/baton/tooling/editorconfig.draft` and `meziantou-ruleset.md`). Set
    `TreatWarningsAsErrors=true`. Fix every resulting diagnostic in the existing code **by fixing the
    code**, never by lowering a severity (A17). Expect real fixes: `ConfigureAwait`, `CA` disposal,
    sealed classes, `TimeProvider` candidates flagged (fix opportunistically or file as B-stage
    followups — do not scope-creep).
  - Gate: `dotnet build Conductor.slnx` 0 warn/0 err **under warnings-as-errors**; 56 tests pass.
- **B0.3** — self-plan + tracker wired.
  - Verify `C:\Code\conductor\bin\conductor.exe run --dry-run -p plans\conductor.self.plan.json`
    prints the B0 session prompt (tracker parses, stage selected, templates resolve).
  - Gate: dry-run output shows stage B0 + the compiled session prompt; committed as evidence.
- **B0.4** — `fake-agent.ps1` scenarios (deliver-success / gates-red / stall) so a `--once` run
  against a scratch tracker exercises the loop without burning tokens.
  - Gate: a scripted `--once` run with the fake agent produces the expected outcome transition
    (recorded in an evidence file).
- **B0.5** — baseline audit doc `docs/baton/audits/B0-baseline.md`: current provider coupling
  (`AgentSession` switch), Loom-isms (`TrackerParser`), mutable-`RunState` coupling, dashboard
  render split, token-lag (F-3), heartbeat pollution (F-4) — each with file:line.
  - Gate: doc exists, every claim cites a file:line.
- **B0.6** — ADRs: `docs/baton/adr/0001-tooling-and-ruleset.md` (why this ruleset, what's disabled and
  why), `0002-event-sourcing.md` (the B2 decision + additive-migration strategy).
  - Gate: both ADRs committed.

## Definition of done
All B0.x DONE; full battery green under warnings-as-errors on net10; dry-run + fake-agent smoke
recorded; baseline audit + ADRs committed. Handoff names the first real B1 action.

## Traps
- Some Meziantou/CA rules will flag a lot at once. Fix in themed commits (async, disposal, sealed),
  each within the diff budget; if a whole class of fixes is large, land the ruleset with that rule
  at `suggestion` and open a followup to ratchet it to `error` in a later stage — but record that
  explicitly in the ADR, never silently.
- Do not refactor logic while migrating TFM — behaviour must not change in B0.1.
