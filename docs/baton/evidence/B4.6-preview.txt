--- B4.6 command-history search + filters (verification notes) ---
Action bar now advertises the searchable pop-out: "[O] history" (was "[O] output").
Opening it (O) captures the merged agent+thinking feed; then:
  * Tab   cycles category filter: all -> commands -> thoughts -> errors -> all
  * /     enters search; type e.g. /build /git /test (slash-token = search term);
          /commands /thoughts /errors also set the category from the typed box.
  * title echoes the live query, e.g. "command history . filter commands . /git".
The modal is interactive, so a redirected preview renders one static frame (above);
the filtered-modal DISPLAY path is proven headlessly by
  CommandHistoryTests.FilteredHistoryRendersOnlyMatchesInTheModal
  (searches "/commands git" -> renders "git status", drops "dotnet build"/"dotnet test").
Preview also seeds a stderr line so the errors category has content to show.
