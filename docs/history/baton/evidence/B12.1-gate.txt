=== Architecture ===
- AnalysisLaneConfig: plan-level config for read-only analysis lanes (StageTrigger, Kind, Prompt, etc.)
- LaneRunner: spawns each lane in a scratch temp dir (like StatusAgent), never writes working tree
- LaneArtifactBattery: IPromptBattery that reads .conductor/lanes/*.md and injects into next prompt
- Orchestrator: starts lanes before RunSession, polls in agent loop, collects artifacts after
- PromptBuilder.BatterySection: includes LaneArtifactBattery when analysis lanes are configured
