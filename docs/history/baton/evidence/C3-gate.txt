--- What landed ---
RollbackExecuted event: added to ConductorEvent.cs schema (type discriminator "rollbackExecuted").
  - Round-trips through JSON with StageId, FromSha, ToSha, Forced fields.
  - Emitted from Orchestrator.HandleControl on successful git reset --hard.

Budget persistence: PerRunCostUsd/PerRunTokens fields added to RunState.
  - Orchestrator restores budget from state on startup (not reset to 0).
  - Budget saved after each session (state.PerRunCostUsd / state.PerRunTokens).
  - Reset on owner approval clears both transient and persisted fields.
  - Survives crashes: killed mid-accrual budget counts toward caps on restart.

Mid-session control feedback: rejected-in-session verbs (RetryStage, Rollback,
  PauseAfterStage, Goto, AbortNow) now log a message when consumed mid-session,
  telling the operator to re-run after session ends. Previously silently dropped.

Orphaned resume hardening: if an orphaned SessionStarted in events.jsonl has no
  AgentSessionId, the orchestrator now marks NeedsHuman instead of silently
  creating a resume with an empty session id (which would start a fresh session).
