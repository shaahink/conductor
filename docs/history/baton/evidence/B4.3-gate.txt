# B4.3 evidence — Hierarchical plan tree (sub-checkpoints; expand/collapse; per-stage cost/attempts/last-outcome)

Generated: 2026-07-08 (session #28, B4 deliver)

## What landed
- `src/Conductor/Ui/PlanTree.cs` (new) — pure plan-tree logic + renderable:
  - `PlanTree.VisibleRows(stages, view)` flattens stages → rows honouring **filter**
    (All/Todo/Active/Failed), free-text **search** (checkpoint id or title, or stage name), and
    **expand/collapse** (active stage auto-expands; a narrowing filter/search auto-expands so
    matches are visible; `E` toggles expand-all; explicit per-stage expand supported).
  - `PlanTree.Build(...)` renders a Spectre table: stage header rows with collapse glyph (`▸`/`▾`),
    per-stage columns folded into one right-aligned meta cell — **done · runs×+last-outcome · cost**
    — and indented `↳` sub-checkpoint rows with short status.
  - `PlanFilter` enum + `PlanTreeView` record (Filter/Search/Expanded/ExpandAll), `NextFilter`
    cycle, `OutcomeAbbr` (compact SessionOutcome tags).
- `src/Conductor/Core/Progress.cs` — new `StageProgress` record (Id/Title/Done/Total/State/
  Attempts/LastOutcome/CostUsd/Checkpoints) + `DashboardSnapshot.Stages` (superset of the legacy
  `StageOverview`/`StageCheckpoints` pair, kept for back-compat).
- `src/Conductor/Core/SnapshotBuilder.cs` — populates `Stages`: attempts = sessions on the stage,
  last-outcome = newest finished session's outcome, cost = Σ session cost. `StageState` factored out
  and shared with `StageOverview` (no duplicated state vocabulary).
- `src/Conductor/Ui/DashboardRenderer.cs` — left column is now **one** unified plan tree panel
  (retired the two stacked `PlanTable` overview + `StageTable` checkpoint panels). The panel header
  shows the active filter chips + search term. `StagesFor` falls back to deriving stages from the
  legacy fields so older snapshots / focused tests still render. Action-bar hint adds `[F] filter`,
  `[E] expand`.
- `src/Conductor/Ui/DashboardState.cs` — carries `PlanTreeView Tree`.
- `src/Conductor/Ui/LiveDashboard.cs` — `F` cycles the filter, `E` toggles expand-all (live + preview
  key handlers); neither cancels a pending destructive confirm.

Diff scope: 8 files (6 src + 2 test), within the ~15 budget.
