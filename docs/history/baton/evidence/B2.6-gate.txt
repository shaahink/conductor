  System.Text.Json source-gen with camelCase compact NDJSON (proven by the round-trip test).

### EMISSION — provider → event log flow ###
- IAgentProvider.cs / AgentStreamState: added optional `onTokenDelta` delegate + EmitTokenDelta method.
- OpencodeProvider.cs: on step_finish, captures per-step delta values and calls state.EmitTokenDelta()
  AFTER accumulating into the state (so both the event log and the agent totals stay consistent).
- AgentSession.cs: accepts IEventSink? parameter (plumbed through Start() → constructor); creates the
  TokenDelta event and enqueues it via the sink. Default null keeps existing callers compiling.
- Orchestrator.cs: passes `events` (the IEventSink) to AgentSession.Start().
