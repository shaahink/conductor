# B1 — Decouple Loom + pluggable progress + conventions + read-order battery

**Stage goal:** make Conductor project-agnostic. Extract Loom to `examples/`, put the
progress/handoff/stage model behind interfaces, and prove it by authoring the first non-Loom plan
(Shamshir parity-pipeline `TRACKER.md`).

**Sessions:** ~3. **Persona:** (default). **Depends on:** B0. **Branch:** `feat/baton-b1`.

## Why (findings)
- F-1: `TrackerParser.cs:38` hard-codes Loom's row regex + `## Handoff`; irregular ids (`P-0`,
  `P3.4b`, `F5`) don't parse; the whole model is Loom-shaped.
- D-2: pluggable `IProgressProvider`; strict `TRACKER.md` is the default & recommended format;
  consolidate docs to one format most of the time, providers are the escape hatch.

## Requirements
- R1.1 Loom plan + templates live under `examples/loom/`; Loom still loads and `--dry-run`s.
- R1.2 `IProgressProvider` abstraction with three implementations; default preserves today's exact
  behaviour (byte-identical parse for the Loom tracker).
- R1.3 Stage-id convention, handoff marker, `HUMAN:` token, and status vocabulary are per-plan config
  with Loom's current values as defaults (back-compatible).
- R1.4 A read-order context battery: a plan lists mandated docs; the session prompt includes the
  ordered read list (bounded).
- R1.5 `conductor new-plan --template {minimal,dotnet,node,shamshir}` scaffolds a plan + TRACKER.
- R1.6 Plan schema `version` + fail-fast validation with actionable messages.

## Definition of done
Loom runs from `examples/loom/`; three providers exist with the default byte-identical to today;
conventions configurable; read-order battery live; `new-plan` works; Shamshir TRACKER template
parses. Full battery green.

## Traps
- Keep `MarkdownTableProvider` byte-identical to the old parser — regressions here silently corrupt
  progress detection on the live Loom shape. Snapshot-test against a real `LOOM-START.md` fixture.
- `ScriptProvider` must be resilient (missing file, malformed JSON → clear error, never a crash that
  parks the run without explanation).
