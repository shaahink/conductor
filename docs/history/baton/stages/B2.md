# B2 — Event-sourced backbone + provider decoupling + Host/DI/logging

**Stage goal:** make the append-only event log the spine. `RunState` becomes a projection; providers
become adapters behind `IAgentProvider`; composition moves to the generic host with structured
logging. Delivered **additively** so resumability never regresses.

**Sessions:** ~3. **Persona:** architect. **Depends on:** B0, B1. **Branch:** `feat/baton-b2`.
This stage precedes B5, B9, B12.

## Why (findings)
- F-9: no event log, no replay, no execution history beyond coarse `RunState.History`.
- F-2: provider parsing is hard-branched in `AgentSession`; adding an agent means editing the core.
- F-3: token/cost only persisted at session end → live burn invisible off-dashboard.
- D-5/D-11/D-12.

## Requirements
- R2.1 `ConductorEvent` typed schema + append-only `.conductor/events.jsonl` writer; every transition
  emits an event. Emitted **alongside** today's `state.json` writes (additive).
- R2.2 `RunState`, `Timeline`, and `Metrics` are projections rebuilt by folding the log; a parity
  test proves the folded `RunState` equals the legacy `state.json` for a recorded run.
- R2.3 Crash recovery replays the event log (superset of today's `RecoverFromCrash`).
- R2.4 `IAgentProvider` abstraction; `Opencode`, `Claude`, `GenericText` adapters; the Orchestrator
  no longer switches on `output`.
- R2.5 `Microsoft.Extensions.Hosting` + DI + Options (validated) compose the app;
  `Microsoft.Extensions.Logging` with Serilog file+console sinks; correlation properties
  (runId/sessionId/stage/gate); every `catch {}` either handles+logs or rethrows (no silent swallow).
- R2.6 `TokenDelta` events per provider `step_finish`, so live token/cost is available to the
  dashboard/report/Telegram from one source.

## Tasks → checkpoints
- **B2.1** — `Core/Events/ConductorEvent.cs` (records, `System.Text.Json` source-gen), append-only
  `EventLog` writer (`Channel`-backed, single writer, flush-safe). Wire emission at each Orchestrator
  transition **in addition to** existing saves.
  - Gate: a self-run (fake-agent `--once`) produces a well-formed `events.jsonl`; schema round-trip
    unit-tested.
- **B2.2** — Projections: `RunStateProjection.Fold(events)` reconstructs `RunState`. `StateCompatTests`
  extended: fold a recorded event stream, assert equality with the legacy `state.json`.
  - Gate: parity test green for a captured stream (Loom-shaped fixture).
- **B2.3** — Crash recovery replays events (interrupted session → queued resume) proven by a test
  that truncates a stream mid-session and recovers.
  - Gate: recovery test green.
- **B2.4** — `Core/Providers/IAgentProvider.cs` + adapters; move `AgentSession`'s per-mode parsing into
  the adapters; Orchestrator depends only on `IAgentProvider`; plan selects by `agent.provider`
  (default inferred from today's `output` for back-compat).
  - Gate: opencode-json + stream-json + text streams each parse via their adapter (unit tests using
    captured `session-*.jsonl` samples); Loom plan still runs (dry-run).
- **B2.5** — Host/DI/Options + logging. `Program.cs` builds a host; services registered; Options
  validated on start; Serilog sinks to `.conductor/logs/` with correlation scope; audit every
  `catch` site.
  - Gate: build green; a run writes a structured log with runId/sessionId; a deliberately-thrown
    error surfaces (not swallowed) in a test.
- **B2.6** — `TokenDelta` events per `step_finish`; a `LiveMetrics` projection exposes current-session
  tokens/cost.
  - Gate: unit test folds token deltas → live totals; wired into the snapshot (verified in B4/B5).

## Definition of done
Event log authoritative-by-parity (state.json still written as a cache); providers decoupled; host +
structured logging; live token events. Full battery green; resumability demonstrably intact.

## Traps
- **Additive discipline:** do not delete `state.json` writing in B2. The cutover to
  projection-as-source happens only after B2.2 parity holds across several recorded runs; even then
  keep `state.json` as a fast-load cache.
- Event writing must be crash-safe (append + flush; never a partial line that breaks the fold). Use a
  single-writer `Channel` drained on a dedicated task; fsync on session boundaries.
- Provider adapters must preserve the exact stall/usage-limit detection behaviour (`DetectsUsageLimit`
  carries today's regex per backend).
