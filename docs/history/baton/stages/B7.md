# B7 — Specialist sub-agent personas

**Stage goal:** turn Conductor from "one agent doing everything" into an orchestrator of specialists.

**Sessions:** ~2. **Persona:** (default). **Depends on:** B2 (provider), B1 (prompt battery).
**Branch:** `feat/baton-b7`.

## Why
- Large plans have qualitatively different work (design vs refactor vs docs vs QA). A per-stage
  persona (system prompt + model/temperature) raises quality and is the substrate B8's self-review
  and B12's read-only lanes build on.

## Requirements
- R7.1 Per-stage / per-checkpoint `agent` override in the plan schema (command, systemPrompt template,
  temperature, token ceiling, provider) — merged over the plan default.
- R7.2 A built-in persona registry with editable templates: `planner`, `reviewer`, `architect`, `qa`,
  `docs`, `refactor`, `test-writer`, `git-cleanup`, `security-audit`.
- R7.3 `PromptBuilder` merges base prompt + persona system prompt + context; the active persona is
  shown in the dashboard, report, and events (`SessionStarted.persona`).

## Tasks → checkpoints
- **B7.1** — schema: `StageConfig.Agent?` (and optional per-checkpoint) override; resolution =
  checkpoint ?? stage ?? plan default.
  - Gate: unit test — a stage with an override resolves to the persona command/prompt; others fall
    back to default.
- **B7.2** — persona registry under `plans/personas/*.md` (self-plan) with a built-in fallback set;
  the `notes: "Persona: architect"` hints in the self-plan become real bindings.
  - Gate: personas load; a missing persona falls back with a clear log line.
- **B7.3** — PromptBuilder merge + surfacing in UI/report/events.
  - Gate: compiled-prompt log shows the merged persona; dashboard shows the persona name (renderer test).

## Definition of done
Personas are first-class and overridable per stage/checkpoint; the self-plan's persona hints become
real. Full battery green.

## Traps
- Persona system prompts must not override the Conductor contract rules (evidence-or-it-didn't-happen,
  ratchet-only). Merge order: contract rules last so they win.
