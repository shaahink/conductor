# B8 — Brain layer

**Stage goal:** close the learning loop — transfer "what was hard" forward, track handover debt,
compose bounded context batteries, and roll long sessions over cleanly.

**Sessions:** ~2. **Persona:** reviewer. **Depends on:** B2, B7. **Branch:** `feat/baton-b8`.

## Why (findings)
- F-7: the audit writes an honest handover nobody reads into the next prompt.
- F-8: bloated contexts (s9: 28.5M cache-read) can only roll at a checkpoint boundary.

## Requirements
- R8.1 Reflection step: at session end, distil the `SESSION-RESULT:` "what was hard" + audit handover
  into a rolling, bounded `.conductor/lessons.md`.
- R8.2 Inject the lessons brief into the next session prompt (`{lessons}` battery) — this is the
  transfer F-7 is missing.
- R8.3 Self-review stage kind (`"kind":"review"`): a stronger model reviews the last N sessions +
  gate results and proposes plan/gate adjustments (advisory; written to a review artifact, not
  auto-applied).
- R8.4 Parse audit handover "weak/deferred/bugs-not-fixed" bullets into tracked
  `.conductor/followups.md`; option to block phase-confirm on an unacknowledged critical gap.
- R8.5 Pluggable `IPromptBattery` list (lessons, DoD-recap from the doc, repo-map/hot-files,
  recent-failure digest) — opt-in per plan, each bounded + deterministic. Token-budget rollover: new
  `RolledOver` outcome (end cleanly + fresh session when `limits.maxSessionTokens` exceeded, no
  attempt burned).

## Tasks → checkpoints
- **B8.1** — reflection → bounded `lessons.md` (rotating, byte-capped).
  - Gate: after a session, lessons.md gains a bounded entry; oldest evicted past the cap (test).
- **B8.2** — `{lessons}` battery injected into the next prompt.
  - Gate: `PromptBuilderTests` — lessons appear in the next prompt; empty when none.
- **B8.3** — self-review stage kind → review artifact.
  - Gate: a review stage produces `.conductor/reviews/<stage>.md`; not auto-applied (test).
- **B8.4** — handover → followups; optional phase-confirm block on critical gap.
  - Gate: a handover with a "deferred: X" bullet yields a followup entry; a critical-flagged gap
    blocks confirm when the option is on (test).
- **B8.5** — `IPromptBattery` list + token rollover.
  - Gate: batteries compose in order, each bounded (test); a session exceeding `maxSessionTokens`
    ends `RolledOver` and the next starts fresh with no attempt burned (fake-agent test).

## Definition of done
Lessons transfer forward; handover debt is tracked; batteries are pluggable+bounded; long sessions
roll over cooperatively-adjacent (hard ceiling here; cooperative soft-break in B9). Full battery green.

## Traps
- Batteries must be BOUNDED and deterministic — an unbounded lessons/repo-map section defeats the
  token-efficiency goal and bloats every prompt. Cap bytes; test the cap.
- `RolledOver` must not burn an attempt and must write a compact handoff first (else the fresh
  session loses context).
