# B5 — Observability & health

**Stage goal:** turn the event log into insight — a timeline, replay/time-travel, execution-health
metrics, and confidence tracking. "Jaeger for AI agents."

**Sessions:** ~2. **Persona:** (default). **Depends on:** B2 (event log), B4 (panes).
**Branch:** `feat/baton-b5`.

## Why (findings)
- F-9: observability is the terminal *now* — no history, replay, or health signal.

## Requirements
- R5.1 Timeline view: every state transition with wall time + duration, from the event log.
- R5.2 Replay / time-travel: reconstruct a past run's outputs/thoughts/commands/gates from
  `events.jsonl` (a viewer, `F8` / `conductor replay <run>`).
- R5.3 AI-health metrics: retry rate, same-command repetition, same-failure loops, tool oscillation,
  context saturation — surfaced in a health panel and in the report.
- R5.4 Confidence per checkpoint (evidence count: tests/files/docs referenced) instead of bare
  "done"; MCP call metrics; repo-awareness strip (branch/dirty/ahead/behind).

## Tasks → checkpoints
- **B5.1** — `Timeline` projection + a TUI timeline view (and REPORT.md section).
  - Gate: timeline renders from a recorded stream; durations correct (unit test on a fixture).
- **B5.2** — replay viewer (`conductor replay <path|run>`), TUI modal `F8`.
  - Gate: replay reconstructs a past self-run's key events in order (test asserts sequence).
- **B5.3** — health metrics computed from the event stream; health panel + report.
  - Gate: synthetic streams (a loop, an oscillation) produce the expected health flags (unit tests).
- **B5.4** — confidence tracking + MCP metrics + repo strip.
  - Gate: a checkpoint shows an evidence-based confidence; repo strip shows ahead/behind (test).

## Definition of done
Timeline + replay + health + confidence all derive from the single event log. Full battery green.

## Traps
- Everything reads the log — do not add a parallel bookkeeping store that can drift (the whole point
  of B2). Metrics are pure folds over events.
- Health heuristics must be conservative (false "looping" alarms erode trust); unit-test thresholds.
