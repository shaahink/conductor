Command contract:
  conductor audit <STAGE> [--replay] [-p|--plan <PLAN>]

  Without --replay: warns and exits 0 (regular audits are orchestrated).
  With --replay:
    1. Loads plan, state, tracker
    2. Finds the stage config (canonical casing)
    3. Gathers context:
       - Stage checkpoints (status, commit, evidence)
       - Git log (20 most recent non-merge commits)
       - Evidence file tails (up to 3 files, 4K chars each)
    4. Builds a structured replay audit prompt (~2-5K chars)
    5. Spawns the plan's agent (scratch dir, read-only)
    6. Saves output to .conductor/audits/<stage>-replay-<timestamp>.md
    7. Prints output to stdout

Prompt structure:
  - Read-only directive (no file modification)
  - Stage identity + notes + checkpoint table
  - Git history with hashes, subjects, authors, timestamps
  - Evidence file contents (tail, truncated at 4K each)
  - Six-section audit rubric: What was built, Correctness,
    Code quality, Testing, Risks & followups, Verdict
