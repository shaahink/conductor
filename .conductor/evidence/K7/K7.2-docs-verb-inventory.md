# K7.2 part 5 — the CLI reference did not name the verbs this era shipped

Session 30, 2026-08-05. K7.1 is DONE and K7.2 is owner-gated, so nothing here is claimed through
`task --done`; this is the fifth defect found in what the ship makes **public**, landed the same way
parts 1–4 were.

## The finding, measured

`docs/cli.md` opens with "This page covers the verbs you reach for daily". It does not cover five of
them. Verb inventory taken from the **fresh build**, not from source reading:

```
dotnet build Conductor.slnx -clp:ErrorsOnly     -> Build succeeded, 0 Warning(s), 0 Error(s)
dotnet run --project src/Conductor --no-build -- --help
```

raw: `.conductor/evidence/K7/K7.2-verbs-engine-help.txt` (41 visible verbs)
raw: `.conductor/evidence/K7/K7.2-verbs-missing-help.txt` (`--help` for each of the five)

Cross-referenced against every user-facing page (`grep -c "conductor <verb>"`):

| verb | `cli.md` | `README.md` | `operating.md` | `quickstart.md` | `docs/README.md` |
|---|---|---|---|---|---|
| `budget`  | **0** | **0** | **0** | **0** | **0** |
| `money`   | **0** | **0** | **0** | **0** | **0** |
| `history` | **0** | **0** | **0** | **0** | **0** |
| `ps`      | **0** | **0** | **0** | **0** | **0** |
| `watch`   | **0** | **0** | 4 | 0 | 0 |

Four of the five are documented **nowhere a user reads**. Two of them — `budget` and `money` — are
this era's flagship, shipped by K4.2 and K4.3, and are what the `v0.4.0` release notes lead with.
`ps` and `history` came from Sarban (SF5.4). At the tag, a reader following the release notes to
`docs/cli.md` would have found the page silent on the feature that sold it.

## Why it rotted — the same rot, already fixed once, in the next room

`SC8.3` hit this exact failure for **shell completion**: the expected verb list was hand-typed in the
test, so `version` shipped missing from both completion scripts *and* from the assertion, and the
test stayed green the whole time. The fix was to read the list off `Program.cs`
(`tests/Conductor.Tests/B11_2Tests.cs:113-170`, `RegisteredVerbs()`).

That scanner was never pointed at the docs. So tab-complete knew about `budget`, `money`, `history`
and `ps`, and the reference page did not. Adding a verb was three places, `SC8.3` made it two, and
the second one was never enforced.

## The fix

1. `docs/cli.md` — `watch` added to **Diagnostics**; new **Token and money** section for `budget` and
   `money`; new **Across runs, on this machine** section for `history` and `ps`. Every flag written
   there was read off the captured `--help`, not from source: `money` really does take
   `--run <ID>`, `--project <PATH>`, `--plan`, `--since`, `--json`
   (`K7.2-verbs-missing-help.txt`, lines 18-25). The `budget` prose states the corrected rule K7.1
   measured — the **nudge**, not only the cap, must clear the median closing session — and points at
   `TOKEN-BUDGET-TUNING.md` rather than restating numbers that move every session.
2. `README.md` — the era's headline ("knows what it did and what it cost") was absent from the front
   door. One paragraph in *Why it can be left alone*, next to the other four.
3. `tests/Conductor.Tests/K7_2DocsVerbCoverageTests.cs` — the guard. Same source-scan as `SC8.3`,
   aimed at `docs/cli.md`: every non-hidden `AddCommand<T>("verb")` must appear on the page as a code
   span. The scan self-checks (`> 30` verbs parsed, or the scanner is broken rather than the docs),
   and the failure message names the missing verbs and the two honest ways out — document it, or
   `.IsHidden()` it if it is not a verb to reach for.

The scanner is deliberately duplicated rather than shared with `B11_2Tests`: the two bars must not be
able to drift by way of a helper one of them later relaxes.

## What this does not fix

`docs/operating.md` ("every control verb") and `docs/quickstart.md` are not pinned by this test —
only `docs/cli.md`, the page whose own first paragraph promises the verb list. `budget`, `money`,
`history` and `ps` are still absent from `operating.md`; that page is about driving a *live* run and
these four are read-only after-the-fact verbs, so the omission is defensible where `cli.md`'s was
not. Named here rather than silently widened: extending the guard to a second page is a judgement
about what that page is for, and it is not this session's to make.
